# TidyTalk — 학생 언어 지도 보조 에이전트 (v0.1)

> 교사가 교실에서 들은 아이들의 표현을 입력하면 **출처 → 위험도 → 개입 판단 → 교정 지침서**를 돌려주는 교사용 AI 에이전트.
> 최종 판단과 학생과의 대화는 항상 교사가 한다. 에이전트는 교사를 대신하지 않고, 교사가 놓치는 것을 보완한다.

## 왜 만들었나

교육봉사 현장과 유아교육 실습 현장에서 반복해서 본 장면:

- 아이들은 SNS·유튜브·게임에서 온 유행어와 은어를 1~2주 안에 모둠 전체로 퍼뜨린다. 그중에는 혐오·비하 표현에서 온 말도 있다.
- 아이들에게 이런 말은 또래 소속감을 확인하는 문화다. 금지한다고 사라지지 않는다.
- 교사가 그 말을 **모르면** 지도 자체가 이루어지지 않는다. **알면** "선생님이 이걸 안다고?"라는 반응과 함께 거리가 생기거나, 반대로 가까워진다. 어떻게 꺼내느냐가 갈림길이다.
- 수업 중 교사에게는 출처를 찾아보고 위험도를 판단하고 대화를 설계할 시간이 없다.

→ 교사의 **인지 → 출처·의미 확인 → 위험도 판단 → 지도 방법 결정** 네 단계 중 앞의 셋을 AI가 보조하고, 마지막은 교사가 한다.

관찰 기록 원본: [`field_notes.md`](field_notes.md) · 써 본 뒤 결론: [`conclusion.md`](conclusion.md)

## 무엇을 하나

| 입력 | 출력 |
|---|---|
| 교사가 들은 표현 한 줄 (+ 선택: 학년, 상황) | ① 출처와 의미 ② 위험도(🟢 지켜보기 / 🟡 가벼운 언급 / 🔴 개별 상담) ③ 개입 여부와 이유 ④ 교사용 교정 지침서(첫 마디, 피해야 할 반응, 대화 흐름 3단계, 순화 표현) ⑤ 판단보류 — 확신이 없으면 단정하지 않고 교사에게 확인 질문 |

### 설계 원칙
1. **문제는 말이지 아이가 아니다.** 아이를 문제아로 규정하는 표현을 쓰지 않는다.
2. **또래 문화는 부정하지 않는다.** 소속감의 욕구는 정상이고, 표현만 바꾸도록 돕는다.
3. **교사는 '아는 어른'이되 '같이 쓰는 어른'은 아니다.** 지침서는 이 균형을 지킨다.
4. **확신 없으면 판단을 보류한다.** 출처가 불확실하거나 맥락이 부족하면 교사에게 묻는다. (※ 팀원의 졸업논문 주제인 '판단보류 기반 인간–AI 협업 검사'와 같은 구조)
5. **최종 판단은 교사가 한다.**

## 구조

```
교사 입력 ──▶ [Dify Chatbot]
                ├─ Instructions: system_prompt.md
                ├─ Knowledge: field_notes.md  (현장 사례 검색)
                └─ Model: gpt-4o-mini
              ──▶ 5단계 출력 (guideline_template.md 양식)
```

## 한계와 다음 단계 (v0.2)
- 출처 정보는 모델 지식 + 관찰 기록에 의존 → 최신 밈은 못 잡을 수 있음. 웹 검색 도구 연결 예정.
- 교사가 실제 대화 후 결과를 입력하면 지침서를 개선하는 피드백 루프 없음 → 교사 메모를 지식베이스로 되돌리는 구조 추가 예정.
- 현재 중학생 관찰 기록 중심 → 유아·초등 사례 보강 필요.
- 현장 교사 2~3명에게 써 보게 하고 피드백 받기.

## 라이선스
관찰 기록과 지침서 양식은 교육 목적으로 자유롭게 사용 가능 (출처 표기). 학생 개인정보는 포함되어 있지 않음.
